## 📷 How to Add Fresh Browser Screenshots

If you would like to capture and add more screenshots of the live running application:

1. **Start WAMP Server:** Ensure WAMP / Apache and MySQL are running (green icon in system tray).
2. **Open the Local Application:**
   - Homepage: `http://localhost/sonali_mutton_shop/`
   - Products Catalog: `http://localhost/sonali_mutton_shop/products.php`
   - Shopping Cart: `http://localhost/sonali_mutton_shop/online_store/cart.php`
   - User Dashboard: `http://localhost/sonali_mutton_shop/user/dashboard.php`
   - Admin Dashboard: `http://localhost/sonali_mutton_shop/admin/index.php`
3. **Capture Screenshots:**
   - Use Windows Snipping Tool (`Windows Key + Shift + S`) or browser developer tools screenshot.
   - Recommended resolution: 1280x720 or 1920x1080.
4. **Safety Check:**
   - Ensure customer phone numbers, personal addresses, order customer details, or admin passwords are **obscured or blurred**.
5. **Save in this folder:**
   - Suggested names:
     - `05-homepage-desktop.png`
     - `06-products-catalog.png`
     - `07-cart-checkout.png`
     - `08-admin-orders-dashboard.png`
